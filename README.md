# 体操競技 遅延再生モニター

スマホ・iPad のカメラで撮った映像を、**指定した秒数だけ遅らせて全画面で流し続ける** Web アプリです。
演技を終えた選手が、モニターの前に戻ってきてすぐに自分の演技を確認できます。

アプリのインストールは不要で、ブラウザで開くだけで使えます。

## アプリを開く

**https://ma2ryusk.github.io/delay_cam/**

スマホ・iPad のカメラで下の QR コードを読み取ってください。

<img src="qr.png" alt="アプリを開くQRコード" width="240">

印刷して配れる説明書（A4・1枚、QR コード付き）：[遅延再生モニター_説明書.pdf](遅延再生モニター_説明書.pdf)

## 使い方

1. 上の URL か QR コードからアプリを開く
2. 「カメラの使用を許可しますか？」と聞かれたら **許可** を押す
3. 端末を三脚などに固定して、演技する場所に向ける
4. 設定した秒数（最初は 10 秒）がたまると、遅れた映像が全画面で流れ始める

右上の **LIVE 小窓** には今のカメラ映像が出るので、画角の確認に使えます。

## 操作

| 操作 | 内容 |
|---|---|
| **−5秒 / −1秒 / +1秒 / +5秒** | 遅延秒数を細かく調整 |
| **数字の欄** | 遅延秒数を直接入力 |
| **5s / 10s / 20s / 40s / 60s** | よく使う秒数にワンタッチで切替 |
| **スライダー** | 1 秒刻みで遅延秒数を調整 |
| **画面を1回タップ** | 操作ボタンを隠して映像だけにする（もう一度タップで表示） |
| **画面をダブルタップ** | 2 倍に拡大／元に戻す |
| **ピンチ・左の +/− ボタン** | 表示を拡大・縮小（拡大中は指でずらせる） |
| **🔄 ボタン（右上）** | 前面カメラと背面カメラを切替 |
| **全画面ボタン（右上）** | ブラウザのアドレスバーなどを隠す |
| **LIVE 小窓をタップ** | 小窓の大きさを切替 |

### 設定（右上の歯車）

- **フレーム数**：1 秒あたりのコマ数を 15／24／30／60 から選択（カメラが対応しない値は選べません）。上げるほど動きがなめらかになり、下げるほど長い遅延をかけられます
- **表示方法**：全画面（画面いっぱいに映し、端を少し切る）／全体（映像全体を映し、黒い帯が出る）
- **カメラ解像度・遅延できる最大**：画質はカメラまかせ（フル HD まで）で、今の画質とコマ数で遅延できる最大秒数の目安を表示
- **左右反転**：鏡のように左右を反転（前面カメラでは自動で ON）
- **常時点灯**：使っている間、画面が暗くならないようにする
- **自動 UI 非表示**：操作しないと 5 秒で操作ボタンを隠す
- **履歴クリア**：たまった映像を消して最初からやり直す

## 注意

- **映像はどこにも送信されません。** 撮影・保存・再生はすべて端末の中だけで行われ、ページを閉じると映像は消えます。
- 映像を保存（録画）する機能はありません。
- 長時間使うとバッテリーを多く使うので、充電しながらの使用をおすすめします。
- 画面ロックや他のアプリへの切り替えでカメラが止まったときは、「カメラを再開する」を押してください。
- おすすめのブラウザ：iPhone・iPad は **Safari**、Android は **Chrome**
